# 安全策略

## 安全边界

Lab Desktop Client 保护 Windows 客户端到远程用户入口之间的连接。

## 安全措施

- SSH 主机指纹首次连接时必须确认；已保存指纹发生变化时阻止连接。
- 密码不进入设置、日志或命令行。用户选择记忆时，密码仅保存在 Windows 凭据管理器。
- VNC、Isaac 信令和媒体转发使用临时本地端口，不公开服务器媒体端口。
- Isaac 会话标识和临时凭据只存在于活动进程内存，并随会话结束清理。
- 内置 WebView 禁止外部导航和开发者工具，并限制可访问的资源与网络目标。
- 客户端只执行固定的 `lab-desktop` 和 `lab-isaac` 协议命令。
- TurboVNC 安装程序从固定官方地址下载，并在执行前校验 SHA-256。
- 日志限制大小且不记录密码；日志故障不改变连接安全判断。

## 用户责任

- 通过独立渠道向管理员核对首次显示的 SSH 主机指纹。
- 主机密钥变化时停止连接，确认变更合法后再删除旧指纹。
- 不在公开 Issue、截图或聊天中提交密码、私钥、临时凭据、完整配置或未经检查的日志。
